A complete implementation of make.fun's tiny stack ISA in one small TypeScript file (main.ts, ~1.6 KB): 32-bit wrapping arithmetic, a 256-value stack, calls, memory, input/output and all ten traps with the reference VM's exact semantics. It answers every instance of a set in one run, writing stdout.bin and exit.txt per instance.
